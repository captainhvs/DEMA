# ⛪ 智能混音助手知识库：混响效果器 (Reverb) 决策与执行指南

## 1. 核心决策逻辑：完全基于用户意图
混响本质上是一种空间声学模拟与艺术化表达工具。Agent 在决定是否使用混响时，**完全取决于用户的明确指令或对环境氛围的描述**。

* **✅ 触发条件（听从用户）**：当用户明确要求“增加空间纵深感”、“模拟房间/大厅/水下环境”、“制造回忆/梦境/孤独的心理氛围”、“让声音更有包裹感”、“让人声和伴奏融合”时，Agent 应当主动应用混响模块。
* **❌ 绝对禁用场景**：如果用户要求处理高精度语音识别任务、科学测量型音频分析，或者要求保留极强、极干脆的瞬态冲击（如干烈的敲击声），又或者音频本身已经存在过强的空间染色（自带混响），Agent 绝不能再添加混响。

## 2. 混响核心参数与工程规则说明
在使用 `pedalboard` 构建混响模块时，Agent 必须理解并配置以下三个核心参数：

* **📏 `room_size` (空间尺度, 范围 0.0 ~ 1.0)**
  * **物理意义**：虚拟空间的物理大小。数值越大，代表声波反射路径越复杂，混响尾音的扩散越长。
  * **取值参考**：`0.1~0.3` 小空间(通信/近场)；`0.3~0.6` 中等室内；`0.6~0.9` 广阔大空间/水下扩散。
* **🌊 `wet_level` (湿信号比例, 范围 0.0 ~ 1.0)**
  * **物理意义**：混响（反射声）信号的输出强度。
  * **取值参考**：`0.1~0.3` 轻度润色；`0.3~0.6` 标准环境模拟；`0.6~0.8` 强烈沉浸感/水下/压抑感。
* **🏜️ `dry_level` (干信号比例, 范围 0.0 ~ 1.0)**
  * **物理意义**：原始未处理信号的保留比例。
  * **取值参考**：`0.8~1.0` 保证主体绝对清晰(语音类)；`0.5~0.8` 空间融合；`0.3~0.5` 强包裹感或极端艺术化处理。

**⚠️ 核心工程平衡规则**：
`wet_level` 升高会导致空间感增强，但必定牺牲声音清晰度；`dry_level` 升高则主体信号更清晰。**在常规混音中，切忌将干、湿信号同时推到极高值**，否则会导致输出电平爆炸与听感极度混乱。

## 3. 常见场景参数参考 (Scenario Defaults)
Agent 应根据用户描述的场景意图，参考以下经验值设定参数组合：

* **🗣️ 轻度空间增强 (Light Space / 润色清晰度优先)**
  * **适用场景**：让人声或乐器不那么干涩，保持绝对清晰度的前提下增加层次。
  * **参数组合**：`room_size = 0.2`, `wet_level = 0.2`, `dry_level = 0.9`
* **🏠 标准空间模拟 (Standard Room / 常规环境)**
  * **适用场景**：一般室内环境模拟、多轨音频常规空间融合。
  * **参数组合**：`room_size = 0.5`, `wet_level = 0.4`, `dry_level = 0.8`
* **🤿 深沉浸/压抑空间 (Deep Immersion / 梦境与水下)**
  * **适用场景**：强空间包裹、心理孤独感压抑表达、水下声学扩散模拟。
  * **参数组合**：`room_size = 0.8`, `wet_level = 0.6`, `dry_level = 0.7`

## 4. Pedalboard 代码实现指南与示例
当你需要生成代码时，只需使用 Python 的 `pedalboard` 库实例化混响模块。
* **依赖项**：导入 `Pedalboard`, `Reverb`。
* **模块化原则**：**请勿包含任何音频文件的读取、写入或导出代码。** 仅需提供构建效果链的函数即可。

**💡 代码示例（单独的混响模块写法）：**

```python
from pedalboard import Pedalboard, Reverb


    """
    根据用户指定的空间场景需求，构建混响效果链模块。
    该模块后续可直接被调用并作用于音频数组。
    """

      Reverb(
          room_size=room_size,
          wet_level=wet_level,
          dry_level=dry_level
      )
