# 🎸 智能混音助手知识库：失真效果器 (Distortion) 决策与执行指南

## 1. 核心决策逻辑：完全基于用户意图
与其他组建不同，**失真本质上是一种艺术化、非线性的能量重塑工具**。因此，Agent 在决定是否使用失真效果时，**完全取决于用户的明确指令或场景描述**。

* **✅ 触发条件（听从用户）**：当用户明确要求“增加声音质感”、“模拟老式收音机/对讲机”、“制造爆炸耳鸣感”、“让声音更脏/更粗糙”时，Agent 应当主动应用失真模块。
* **❌ 绝对禁用场景**：如果用户要求处理科学分析型音频、高保真语音识别任务，或需要极高自然度表达的素材（如纯净的自然环境声），Agent 绝不能添加失真效果。

## 2. 失真核心参数与工程规则说明
在使用 `pedalboard` 构建失真模块时，Agent 必须理解并配置以下两个核心参数，且**严格遵守增益补偿规则**：

* **🎛️ `drive_db` (驱动量/失真度)**
  * **物理意义**：控制输入信号进入非线性放大器的强度。
  * **听觉效果**：数值越大，信号被“挤压”得越厉害，产生的高频谐波成分越多，声音听起来越密集、越粗糙、质感越强。
* **⚠️ `gain_db` (补偿增益 - 强制配套使用)**
  * **核心工程规则**：失真（Drive）本质上是一种放大行为，会引入剧烈的能量膨胀。如果不进行输出控制，会导致严重的削波（Clipping）和数字爆音。
  * **补偿公式**：在效果链中，`Distortion` 后面必须紧跟 `Gain` 模块进行衰减。经验补偿公式为：`gain_db ≈ -0.5 * drive_db`。

## 3. 常见场景参数参考 (Scenario Defaults)
Agent 应根据用户描述的场景意图，参考以下经验值设定 `drive_db`，并自动计算对应的 `gain_db`：

* **📻 轻度饱和 (Light Saturation / 模拟电子管质感)**
  * **适用场景**：微弱质感增强、让单薄的声音变厚实、旧式电子设备模拟。
  * **参数组合**：Drive `15.0 dB` 搭配 Gain `-7.5 dB`
* **📞 标准失真 (Standard Distortion / 战术通信)**
  * **适用场景**：对讲机通信、无线电模拟、增加明显的粗糙纹理。
  * **参数组合**：Drive `25.0 dB` 搭配 Gain `-12.5 dB`
* **💥 强失真 (Heavy Distortion / 极端压迫感)**
  * **适用场景**：战场环境、爆炸后的耳鸣感、极端心理压迫表达。
  * **参数组合**：Drive `40.0 dB` 搭配 Gain `-20.0 dB`

## 4. Pedalboard 代码实现指南与示例
当你需要生成代码时，只需使用 Python 的 `pedalboard` 库实例化失真与增益模块。
* **依赖项**：导入 `Pedalboard`, `Distortion`, `Gain`。
* **模块化原则**：**请勿包含任何音频文件的读取、写入或导出代码。** 仅需提供构建效果链的函数。
* **顺序原则**：在链条中，必须是先 `Distortion`，后 `Gain`。

**💡 代码示例（单独的失真与补偿模块写法）：**

```python
from pedalboard import Pedalboard, Distortion, Gain


    """
    根据用户指定的失真强度 (drive_db)，构建包含自动增益补偿的效果链模块。
    该模块后续可直接被调用并作用于音频数组。
    """
    # 强制工程规则：计算并应用增益补偿，防止削波失控
    # 经验公式：Gain = -0.5 * Drive
    compensation_gain_db = -0.5 * drive_db

    # 构建效果链，严格遵守顺序：先 Distortion (放大失真) -> 后 Gain (衰减补偿)
    Distortion(drive_db=drive_db),
    Gain(gain_db=compensation_gain_db)
