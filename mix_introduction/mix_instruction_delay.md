# ⏱️ 智能混音助手知识库：延迟效果器 (Delay) 决策与执行指南

## 1. 核心决策逻辑：完全基于用户意图与“混响”的区别
延迟（Delay）与混响（Reverb）属于同类空间时间效果器，但听感完全不同。Agent 在决定是否使用延迟时，**完全取决于用户的明确指令**。

* **⚠️ 延迟与混响的核心区别**：
  * **混响 (Reverb)**：是无数个反射声融合在一起的**模糊残响**，听不清具体的字眼（像在大教堂里说话，声音是一片晕开的）。
  * **延迟 (Delay)**：是清晰的、节奏分明的**可数回声**（像在空旷的山谷里大喊“喂”，能清楚听到后续的“喂...喂...喂...”）。
* **✅ 触发条件（听从用户）**：当用户明确要求“加点回声”、“让声音有清晰的拖尾”、“增加声音的律动感”、“做一点 Slapback 效果”、“制造山谷里的回音”时，Agent 应当主动应用延迟模块。
* **❌ 禁用场景**：如果用户要求的是“空间包裹感”、“房间感”或“让声音不要这么干”，但没有提到“回声”或“拖尾”，请优先使用**混响 (Reverb)** 而不是延迟。

## 2. 延迟核心参数与工程规则说明
在使用 `pedalboard` 构建延迟模块时，Agent 必须理解并配置以下三个核心参数：

* **⏳ `delay_seconds` (延迟时间, 单位：秒)**
  * **物理意义**：原始声音与第一个回声之间的时间差。
  * **取值参考**：`0.05~0.15` 极短（Slapback/拍声延迟，常用于复古人声/吉他）；`0.2~0.5` 中等（最常见的人声拖尾）；`0.5~1.0+` 极长（山谷回音、大空间长拖尾）。
* **🔁 `feedback` (反馈量, 范围 0.0 ~ 1.0)**
  * **物理意义**：回声重复的次数。数值越大，声音在彻底消失前重复的次数越多。
  * **⚠️ 核心安全规则**：**绝不能将 `feedback` 设置为 1.0 或更高**，否则会导致信号无限循环放大，最终爆音毁掉喇叭。常规使用请严格控制在 `0.1 ~ 0.6` 之间。
* **🚰 `mix` (干湿比, 范围 0.0 ~ 1.0)**
  * **物理意义**：原始信号（干声）与回声信号（湿声）的混合比例。
  * **取值参考**：`0.1~0.3` 作为隐形润色，不抢主体风头；`0.4~0.5` 明显的回声效果；`1.0` 纯回声（通常仅在特殊的辅助发送轨 Aux Send 中使用，串联混音中极少用）。

## 3. 常见场景参数参考 (Scenario Defaults)
Agent 应根据用户描述的场景意图，参考以下经验值设定参数组合：

* **🎸 Slapback / 复古拍声 (极短回声)**
  * **适用场景**：50年代复古人声、乡村吉他，增加声音厚度和打击感，但不拖泥带水。
  * **参数组合**：`delay_seconds = 0.1`, `feedback = 0.1` (几乎只重复一次), `mix = 0.25`
* **🎤 流行人声拖尾 (Vocal Tail / 标准回声)**
  * **适用场景**：让对白或歌唱的句尾有自然的延伸感，增加律动。
  * **参数组合**：`delay_seconds = 0.35`, `feedback = 0.3` (重复两三次后消失), `mix = 0.2`
* **⛰️ 深渊山谷 / 迷幻回音 (Deep Canyon / Psychedelic)**
  * **适用场景**：空旷环境的呐喊、强烈的艺术化空灵感表达。
  * **参数组合**：`delay_seconds = 0.8`, `feedback = 0.5` (绵长的多次回声), `mix = 0.4`

## 4. Pedalboard 代码实现指南与示例
当你需要生成代码时，只需使用 Python 的 `pedalboard` 库实例化延迟模块。
* **依赖项**：导入 `Pedalboard`, `Delay`。
* **模块化原则**：**请勿包含任何音频文件的读取、写入或导出代码。** 仅需提供构建效果链的声明过程即可。

**💡 代码示例（单独的延迟模块写法）：**

```python
from pedalboard import Pedalboard, Delay



    根据用户指定的空间回声需求，构建延迟效果链模块。
    请务必确保 feedback 小于 1.0 以防止爆音。
    """

    Delay(
        delay_seconds=delay_seconds,
        feedback=feedback,
        mix=mix
    )
